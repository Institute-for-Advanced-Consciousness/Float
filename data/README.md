# Data Directory

Place your data files here:
- `raw_data.csv`
- `only_complete_data.csv`
- `phenom_psilo_float.csv`
- `final_schedule_binary.xlsx` (for Measure Admin. Supp. Table)

These files are not tracked by git (see .gitignore).

After running `01_data_cleaning.R`, this folder will also contain:
- `cleaned_data.rds` (processed data object)
